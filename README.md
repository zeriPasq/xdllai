# ИИ-бот для Telegram (на базе DeepSeek через sums001/Deepseek-API)

## Что делает
- Отвечает на все сообщения в личке
- В группах отвечает когда его упоминают (@бот), отвечают на его сообщение, или в тексте
  встречается одно из слов-триггеров (список в `TRIGGER_WORDS` в bot.py, по умолчанию "хдлл" и юзернейм бота)
- Помнит контекст диалога отдельно для каждого чата (последние 50 сообщений)
- `/reset` — очистить память диалога
- Полная админ-панель: вкл/выкл бота, баны юзеров и групп, управление админами, настраиваемый промпт
- `/say` — отправить сообщение в любой чат/группу от имени бота: жмёшь кнопку с нужным чатом
  (id + название), потом пишешь текст. Список кнопок пополняется автоматически — бот запоминает
  каждый чат, где ему хоть раз написали
- Журнал событий (`/logs`) — все вопросы, ответы бота и ошибки пишутся в лог, доступный из Telegram
- Антикраш-система: если подряд накопилось много ошибок (например, DeepSeek-сервер упал), бот сам себя выключает и пишет владельцу лично, вместо того чтобы спамить ошибками во все чаты
- Настройки и логи хранятся в `bot_data.json` рядом с ботом — переживают перезапуск

## Админ-команды
Полный список: `/help` (для админа покажет отдельным блоком)

| Команда | Что делает |
|---|---|
| `/enable` / `/disable` | вкл/выкл бота глобально |
| `/status` | статус, счётчик ошибок, статистика |
| `/promptmenu` | меню управления главным системным промптом: изменить / показать / сбросить на дефолтный |
| `/setprompt <текст>` | быстро задать промпт без меню, если так удобнее |
| `/getprompt` | посмотреть текущий промпт |
| `/banuser <id>` или реплай | забанить юзера — бот перестаёт ему отвечать везде |
| `/unbanuser <id>` или реплай | разбанить |
| `/banlist` | список забаненных |
| `/bangroup` | забанить текущую группу целиком |
| `/ungroup` | разбанить группу |
| `/addadmin <id>` / `/deladmin <id>` | управление админами (можно по реплаю) |
| `/adminlist` | кто сейчас админ |
| `/say` | отправить сообщение в чат — выбираешь кнопкой, потом пишешь текст (или `/say <chat_id> <текст>` одной командой) |
| `/logs [N]` | последние N событий: вопросы, ответы, ошибки (по умолчанию 20, максимум 100) |
| `/clearlogs` | очистить журнал |

Чтобы забанить/разбанить/выдать права по человеку — проще всего ответить на его сообщение нужной командой, не вводя id вручную.

### Как пользоваться /say
Просто напиши `/say` — бот покажет кнопки со всеми чатами, где он засветился (имя + id).
Жмёшь на нужный чат, потом следующим сообщением пишешь текст — он уйдёт туда от имени бота.
Если чата ещё нет в списке (бот там ни разу не отвечал) — можно указать id вручную:
`/say -1001234567890 Текст сообщения`. Отменить выбор чата — `/cancel`.

### Триггер-слова
Заданы фиксированным списком в `bot.py`:
```python
TRIGGER_WORDS = [
    "хдлл",
    "@xdllai_bot",
]
```
Если сообщение в группе содержит любое из этих слов (без разницы, где — в начале, середине,
с упоминанием или без), бот отвечает, даже если это не прямой реплай. Чтобы поменять список —
просто отредактируй его в коде и перезапусти бота.

## Установка

### 1. Подними DeepSeek-API сервер
```bash
git clone https://github.com/sums001/Deepseek-API
cd Deepseek-API
# следуй инструкции репозитория: установка зависимостей + логин в браузере
# после запуска сервер слушает http://localhost:8000/v1
```

### 2. Получи токен бота
Напиши @BotFather в Telegram → `/newbot` → следуй инструкциям → сохрани токен.

Там же, если бот будет в группах:
```
/setprivacy -> выбери бота -> Disable
```
Это нужно, чтобы бот видел все сообщения в группе, а не только команды.

### 2.1 Узнай свой Telegram ID (для админки)
Напиши боту @userinfobot — он пришлёт твой числовой id. Это будет `OWNER_ID` —
только у тебя будет неотзываемый доступ к админ-панели.

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. Задай переменные окружения и запусти
```bash
export TELEGRAM_TOKEN="твой_токен_от_botfather"
export OWNER_ID="твой_id_от_userinfobot"
export DEEPSEEK_BASE_URL="http://localhost:8000/v1"   # можно не менять, если по умолчанию
python bot.py
```

Без `OWNER_ID` админ-команды будут недоступны никому.

## Настройка под себя
Всё в начале `bot.py` в секции НАСТРОЙКИ:
- `HISTORY_LIMIT` — сколько сообщений помнить (по умолчанию 50)
- `MODEL_NAME` — `deepseek-chat` (быстрый) или `deepseek-reasoner` (думает дольше, лучше в сложных задачах)
- `MAX_CONSECUTIVE_ERRORS` — после скольких ошибок подряд бот сам выключится

Характер бота (системный промпт) теперь настраивается не в коде, а прямо из Telegram
командой `/setprompt` — сохраняется в `bot_data.json` и переживает перезапуск.

## Важно знать
- sums001/Deepseek-API — неофициальный проект, обрабатывает запросы **последовательно**.
  Если несколько друзей спросят одновременно — будет небольшая очередь.
- Не для больших нагруженных групп — для компании друзей самое то.
- Добавь бота в группу, права администратора не нужны, достаточно обычного участника.
- Файл `bot_data.json` создаётся автоматически при первом запуске рядом с `bot.py`.
  Не удаляй его, если хочешь сохранить настройки/баны между перезапусками.
- Первый добавленный админ (кроме владельца) может банить и разбанивать всех, кроме
  владельца — так что добавляй только тех, кому реально доверяешь.
